# Fathom Aquarium 🐠

여름방학 예습·복습용 Extensive Reading 학습 웹앱입니다.
할 일(예습/복습/퀴즈)을 끝내면 알을 받고, 부화시켜 나만의 아쿠아리움을 채워요.

Claude Design 프로토타입(`ER 프로토타입.dc.html`)을 그대로 옮긴 정적 웹앱으로,
빌드 도구 없이 브라우저에서 바로 동작합니다.

## 실행 방법

빌드가 필요 없습니다. 아래 중 편한 방법으로 열면 됩니다.

- `index.html` 파일을 브라우저로 바로 열기 (더블클릭)
- 또는 간단한 로컬 서버 실행:

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### GitHub Pages로 배포하기

저장소 Settings → Pages → Branch를 `main`(root)으로 지정하면
`https://<계정>.github.io/Reading_Aquarium/` 주소로 접속할 수 있습니다.

## 기능

### 학생 모드
- **오프닝** — 물속 거품 연출과 함께 "화면을 탭하여 시작"
- **홈** — 오늘 선생님이 고른 문장, 지금 읽는 책, 오늘 할 일 4개(지문 예습·지문 복습·어휘 복습·문장 복습), 보너스 학습 3개(어휘 예습·문장 예습·어법 퀴즈)
- **퀴즈** — 객관식 + 주관식(입력), 정답 확인·해설, 결과 화면(점수/오답 다시보기)
- **지문 복습** — 본문 속 단어를 탭하면 뜻 팝오버 표시
- **e-북 리더** — 책 본문 3페이지, 진행률 표시
- **보상 시스템** — 할 일 완료 시 +15 XP, 오늘 할 일 4개를 모두 끝내면 알 1개 지급, XP 50으로 알 구매 가능
- **부화장** — 알 부화 시네마틱(균열 → 껍질 열림 → 등장), 등급별 확률(NORMAL/SPECIAL/RARE/SUPER RARE/UNIQUE), 5회마다 SUPER RARE·10회마다 UNIQUE 보장
- **아쿠아리움** — 부화한 동물들이 픽셀 아트로 헤엄치는 수조, 레벨/XP 진행바
- **도감** — 28종 수집 현황 (미발견 종은 실루엣으로 표시)

### 교사 모드
- 반 현황 대시보드 — 복습 완료율, 어휘시험 평균, 사색질문 답변률, 미완료 학생
- 학생별 현황 표, 사색 질문 답변 모아보기

## 구조

```
index.html      앱 진입점
css/style.css   프레임·애니메이션 스타일
js/data.js      동물 도감(28종 픽셀 스프라이트)·등급·퀴즈·책 본문 데이터
js/app.js       상태 관리 + 화면 렌더링 (순수 JS, 프레임워크 없음)
```

학습 진행 상황(할 일 완료, XP, 보유 동물 등)은 브라우저 `localStorage`에 저장됩니다.
초기화하려면 개발자 도구 콘솔에서 `localStorage.removeItem('er_aquarium_v1')` 실행 후 새로고침하세요.
